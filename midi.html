.vpr (VOCALOID5/6 프로젝트)

VOCALOID7에서 File → Open으로 바로 엽니다. 음표마다 발음기호가 보호(Phoneme Lock)된 상태로 들어가므로 변환기에서 본 발음 그대로 부릅니다. 연 다음 트랙의 보이스뱅크를 선택하세요.

가사 넣은 .mid

.vpr이 열리지 않을 때 쓰는 안전한 방법. File → Import File로 MIDI를 가져올 때 가사 인코딩을 UTF-8로 고르고, 가져온 뒤 Job → Convert Phonemes to Match Language를 실행하세요.

음표 처리 규칙

가장 음표가 많은 트랙을 자동 선택합니다. 화음은 가장 높은 음만 남기고, 겹치는 음표는 다음 음표 시작 지점에서 자릅니다. "받침을 별도 음표로"를 켜면 받침도 음표 하나를 차지합니다.

BETA .vpr 형식은 공개 사양이 없어 직접 맞춰 만든 것입니다. VOCALOID7에서 열리지 않거나 보이스가 비어 있으면 가사 넣은 .mid를 사용해 주세요.

비공식 도구입니다. .vpr 형식은 공개 사양이 없어 직접 맞춰 만든 베타 기능입니다.
