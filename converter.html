한국어 발음 변환기

한국어 가사를 입력하면, 일본어·영어 보이스가 한국어처럼 부르도록 비슷한 발음의 표기로 바꿔 줍니다. 결과를 복사해 VOCALOID7에 붙여넣으세요.

각 칸을 누르면 그 음절만 복사됩니다. 영어 칸 아래 작은 글씨는 VOCALOID 영어 발음기호입니다.

VOCALOID7에 넣는 방법

1 · 음표 먼저

한국어 한 글자당 음표 하나씩 그려 두세요. "받침을 별도 음표로"를 켰다면 받침 몫의 음표(짧게)도 추가합니다.

2 · 일괄 삽입

첫 음표를 선택하고 Ctrl/⌘+I (Insert Lyrics) → 복사한 가사 붙여넣기. 공백 단위로 음표에 차례대로 들어갑니다.

3 · 발음기호로 다듬기

영어 철자가 어색하게 들리면 Ctrl/⌘+R로 Phonetic Symbols Mode로 바꾸고, 칸 아래 발음기호를 해당 음표에 붙여넣으세요.

알아두기 혼합 모드는 받침이 없고 일본어에 가까운 음절은 가나로, ㅓ·ㅡ나 받침(ㄱ·ㄷ·ㅂ·ㄹ·ㅁ)이 있는 음절은 영어로 표기합니다. 언어를 섞어 부를 수 있는 다국어 보이스에서만 동작합니다. 변환은 근사치이므로 마지막엔 귀로 확인하고 다듬어 주세요.

.vpr (VOCALOID5/6 프로젝트)

VOCALOID7에서 File → Open으로 바로 엽니다. 음표마다 발음기호가 보호(Phoneme Lock)된 상태로 들어가므로 변환기에서 본 발음 그대로 부릅니다. 연 다음 트랙의 보이스뱅크를 선택하세요.

가사 넣은 .mid

.vpr이 열리지 않을 때 쓰는 안전한 방법. File → Import File로 MIDI를 가져올 때 가사 인코딩을 UTF-8로 고르고, 가져온 뒤 Job → Convert Phonemes to Match Language를 실행하세요.

음표 처리 규칙

가장 음표가 많은 트랙을 자동 선택합니다. 화음은 가장 높은 음만 남기고, 겹치는 음표는 다음 음표 시작 지점에서 자릅니다. "받침을 별도 음표로"를 켜면 받침도 음표 하나를 차지합니다.

BETA .vpr 형식은 공개 사양이 없어 직접 맞춰 만든 것입니다. VOCALOID7에서 열리지 않거나 보이스가 비어 있으면 가사 넣은 .mid를 사용해 주세요.

비공식 도구입니다. 변환 결과는 보이스뱅크·스타일에 따라 다르게 들릴 수 있습니다.
