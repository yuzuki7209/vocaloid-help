VOCALOID7 Editor 가이드

처음 켜는 순간부터 WAV로 내보내기까지. 왼쪽 목차나 상단 검색(/)으로 바로 찾아가세요.

01

빠른 시작

설치 후 첫 노래를 만들기까지 다섯 단계.

  1. 홈 화면에서 NEW PROJECT

    에디터를 켜면 홈 창이 뜹니다. NEW PROJECT를 누르면 메인 창과 함께 트랙 추가 대화상자가 열립니다. 예제가 궁금하면 OPEN DEMO SONG (문서 폴더로 복사되어 열림).

  2. 트랙 추가 → 보이스 선택

    트랙 종류 VOCALOID, 보이스(예: V7 / asa), 트랙 이름, 파트 길이(마디)를 정하고 Add. 나중에 T 키로 언제든 추가할 수 있습니다.

  3. 파트를 더블클릭 → 음표 그리기

    트랙의 파트를 열면 하단에 뮤지컬 에디터(피아노롤)가 나타납니다. 연필 툴(2)로 드래그해 음표를 그립니다.

  4. 가사 입력

    음표 선택 후 Enter 또는 더블클릭 → 가사 입력 → Tab으로 다음 음표. 여러 음표에 한꺼번에 넣으려면 Ctrl/⌘+I (Insert Lyrics).

  5. 재생하고 내보내기

    Space로 재생. 파트가 왼쪽부터 칠해지는 부분이 합성 완료된 구간입니다. 완성되면 Ctrl/⌘+E (Audio Mixdown)로 WAV/MP3 저장.

TIP 파트는 통째로 합성됩니다. 10분 넘는 긴 파트는 합성이 끝날 때까지 들을 수 없으니, 가위 툴(3)로 짧게 나눠 작업하면 훨씬 빠릅니다.
02

화면 구성

메인 창은 다섯 구역으로 나뉩니다.

툴바 · 트랜스포트 · 타임 디스플레이
INSPECTORF5 · 트랙/음표 설정
TRACK EDITOR트랙과 파트 배치
BROWSER보이스뱅크 · 웹
LOWER ZONE — MUSICAL EDITOR (F2) / WAVE EDITOR / MIXER (F3)

파트 종류

VOCALOID:AI 파트 — V6 이후 보이스뱅크. 피치·비브라토·표현·타이밍 툴 사용 가능.
VOCALOID 파트 — V3~V5 보이스뱅크. 이모션 툴·어택/릴리즈 이펙트 사용.
오디오 파트 — WAV/MP3 반주.

트랙 헤더

색상(우클릭, 16색) · 이름 · 보이스뱅크 · E 이펙트 · M 뮤트 · S 솔로(길게 누르면 Solo Defeat) · R 녹음 · 볼륨 · 팬.

특수 트랙

TIMESIG 박자, TEMPO 템포(연필/라인 툴로 입력), MAIN 마스터 볼륨과 마스터 이펙트. 상단 버튼으로 표시/숨김.

03

트랙 에디터

곡 전체 구조를 짜는 곳. 파트를 만들고, 옮기고, 자릅니다.

1

화살표

선택·이동. Ctrl/⌘+클릭 다중 선택, 드래그로 범위 선택.

2

연필 / 라인

새 파트, 볼륨·팬 오토메이션, 템포·박자 입력. 다시 클릭하면 라인 툴로 전환. Alt/⌥ 누르는 동안 임시 연필.

3

가위

파트를 둘로 나눕니다.

×

뮤트

선택한 파트를 뮤트/해제. 뮤트된 파트는 재생되지 않음.

⊞

그리드

입력 위치를 1/4 등 단위로 스냅. "T"는 셋잇단. Ctrl/⌘ 누르는 동안 임시 해제.

반복 재생 구간 만들기

  • 룰러의 시작/끝 마커를 드래그 → 리피트 자동 ON.
  • 파트 선택 후 P — 그 파트 범위를 반복 구간으로.
  • Mac: ⌥+클릭 = 시작 마커, ⌘+클릭 = 끝 마커 · Windows: Ctrl+클릭 = 시작, Alt+클릭 = 끝.
  • C로 리피트 켜기/끄기.

파트 우클릭 메뉴

Create Part on Song Position

현재 재생 위치에 새 파트 생성.

Double Tempo

파트 길이를 절반으로 → 템포가 두 배처럼 들림.

Half Tempo

파트 길이를 두 배로 → 템포가 절반처럼 들림.

오토메이션 볼륨/팬 슬라이더 왼쪽의 >를 누르면 오토메이션 레인이 열립니다. 연필로 포인트를 찍어 곡선을 그리세요.

뮤지컬 에디터

피아노롤에서 음표와 노래 표현을 다듬는 핵심 공간.

1

화살표

음표·파라미터 포인트 선택 및 이동.

2

연필 / 라인

음표·파라미터 입력. Shift 누르는 동안 임시 연필.

3

가위

음표 분할. 발음기호 잠금은 풀림. 그리드에 맞춰 분할.

×

뮤트

음표 단위 뮤트.

표현 툴 AI 파트

4

피치

앞/뒤 트랜지션, 미세조정, 드리프트를 핸들로 조절. 피치 펜슬로 직접 그리고 지우개로 삭제(펜슬/지우개는 VOCALOID 파트도 가능).

5

비브라토

깊이·속도·시작 위치를 음표 위에서 바로 조절.

6

익스프레션

음표 앞·중간·뒤 강약(Leading/Middle/Following).

7

타이밍

음소(phoneme) 단위로 발음 시점을 앞뒤로 이동.

E

이모션 VOCALOID 파트

주황 띠를 클릭해 Accent 조절. 자음 시작이면 왼쪽 끝을 끌어 자음 길이(Velocity) 조절. 비브라토 이펙트가 있으면 패드로 주기·진폭 조절.

편집 꿀기능

Action 메뉴

Convert to Breath — 음표를 숨소리로.
Convert to Silence — 음표를 무음으로.

Job 서브메뉴

스타카토 · 균등 분할 · 지정 위치 분할 · 합치기 · 겹침 해결 · 쉼표 삽입 · 조옮김(반음 단위). 선택이 없으면 파트 전체에 적용.

Quantize

Q 그리드에 정렬, Shift+Q 50%만 가까이.

Paste Special

가사/피치/비브라토/익스프레션 등 원하는 항목만 골라 붙여넣기.

Fix / Unfix Pitch

음표별 피치를 고정하거나, 해제해 시스템이 다시 계산하게 함.

Auto Vibrato

AI 트랙은 음표 입력·길이 변경·복제·불러오기 시 자동 비브라토. 인스펙터에서 Vibrato > Manual을 켜면 자동 적용 제외.

보기 옵션 툴바에서 피치 곡선(주황선), 파형, 보이스뱅크 이미지 표시를 켜고 끌 수 있습니다. 보이스뱅크 이미지는 PNG(최대 1024×1024)를 끌어다 넣어 직접 바꿀 수 있어요.
05

가사 입력

키보드만으로 빠르게 가사를 붙이는 법.

두 가지 입력 모드 Ctrl/⌘+R

  • Letter Mode — 일반 글자로 가사 입력 (예: 사랑, love, あい).
  • Phonetic Symbols Mode — 발음기호를 직접 편집 (예: s a).

알아두면 좋은 것

  • 후보가 여러 개면 입력창 아래 드롭다운으로 발음/언어 선택.
  • 하이픈 - = 멜리스마. 앞 음표의 모음을 이어 부릅니다.
  • 다국어 보이스는 한 곡에 언어를 섞어 쓸 수 있음.
  • 음표 우클릭 → Phoneme Lock으로 발음기호 보호(자동 변환 제외).
  • 보이스 언어를 바꿨다면 Job → Convert Phonemes to Match Language.
  • 파트 밖에 음표를 찍으면 가장 가까운 파트가 자동으로 늘어납니다.

06

컨트롤 파라미터

음표 아래 레인에 곡선을 그려 소리를 시간에 따라 바꿉니다. Ctrl/⌘+P로 표시/숨김.

값 직접 입력 포인트를 선택하면 왼쪽 텍스트박스에 값이 표시됩니다. 여러 개를 선택하고 값을 입력하면 한꺼번에 적용. 화살표 툴로 점을 더블클릭해도 입력창이 뜹니다.
07

인스펙터

F5. 트랙을 고르면 트랙 인스펙터, 음표를 고르면 노트 인스펙터.

TRACK 인스펙터

  • VOICE / TYPE — 보이스와 보이스 타입 선택.
  • STYLE — 트랙 전체 노래 스타일 프리셋. 바꿔도 직접 그린 파라미터는 유지. 💾 버튼으로 내 프리셋 저장.
  • BREATH — 숨소리 자동 삽입. 빈도 + EXHALATION(볼륨).
  • ROBOT VOICE — HARD / NORMAL / SOFT.
  • SINGING SKILL V 파트 — 피치벤드·다이내믹스 자동 적용 (SKILL, AMOUNT).
  • VOICE COLOR — 파라미터 전체에 오프셋. EXPRESSION 0~100 (AI) · AIR −100~+100 (AI) · CHARACTER −64~+63 · ATTACK −100~+100 (V7 보이스) · EXCITER/GROWL/BREATHINESS/MOUTH (V 파트)
  • TAKE V 파트 — 발음 타이밍 변형.

NOTE 인스펙터

  • LYRIC / PHONETIC SYMBOL — 가사와 발음기호 편집, 🔒 버튼으로 보호.
  • ATTACK / RELEASE EFFECT V 파트 — 음표 앞/끝에 효과. 아이콘 클릭으로 적용, 다시 클릭 해제. 강도 SOFT 0.0 ~ HARD 1.0. 분류: Pitch · Dynamics · Tone · Ornamentation. 보이스 전용 효과는 탭 상단에.
  • PARAMETER AI 파트 — 숫자로 정밀 조절: Pitch: Leading/Following Transition, Fine Tune, Leading/Overall/Following Drift
    Vibrato: Manual, Rate, Depth, Vibrato Start, Leading/Following Depth
    Expression: Leading/Middle/Following
08

오디오 이펙트

트랙의 E 버튼 또는 믹서의 EFFECT 버튼으로 엽니다.

  • 추가 오른쪽 Effect List에서 클릭
  • 삭제 다시 클릭 또는 우클릭 → Delete Audio Effect
  • 바이패스 각 이펙트 좌상단 스위치 / 리스트 우측 스위치로 전체
  • 순서 드래그 앤 드롭
  • 프리셋 각 이펙트 우상단 목록
09

웨이브 에디터 · 믹서

반주 오디오 다루기와 최종 밸런스.

오디오 넣기

Finder/탐색기에서 WAV·MP3를 끌어다 놓기. 내부적으로 44.1kHz/16bit로 변환됩니다. 지원: WAV 8/16/24bit·32bit float, 44.1~192kHz / MP3 128~320kbps.

Change Pitch

오디오 음정을 −12 ~ +12 반음(±1200 cent) 변경.

Time Stretch

파트 오른쪽 끝을 Alt/⌥+드래그. 0.5배 ~ 4배.

Normalize

Alt/⌥+N. 오디오 파트 최대 레벨을 0dBFS로.

믹서 (F3)

트랙별 EFFECT · OUTPUT 라우팅 · 팬 · 볼륨 페이더 · M/S/R. 오른쪽 끝이 MAIN.

기본값 복귀

페이더·노브를 Ctrl/⌘+클릭하면 기본값으로 리셋.

  • Revert — 마지막 저장 상태로 되돌리기.

보이스뱅크에 포함된 무료 에디터.

EDITOR (유료)

  • 트랙 수 제한 없음
  • VST / AU / ARA / Cubase 연동
  • 모든 기능

LITE (무료)

  • VOCALOID 트랙 1개 + 오디오 트랙 1개
  • DAW 플러그인으로 에디터 화면 열리지 않음
  • 기간 제한 없음 (보이스뱅크 1개 이상 인증 필요)
주의 유료판 프로젝트를 Lite로 열면 번호가 가장 낮은 트랙만 불러오고, 그 상태로 저장하면 나머지 트랙은 삭제됩니다. 유료판 시리얼로 재인증하면 재설치 없이 업그레이드됩니다.

자주 묻는 질문

매뉴얼에서 자주 헷갈리는 포인트.

재생해도 소리가 안 나요 / 늦게 나와요

파트는 왼쪽부터 칠해지며 합성됩니다. 칠해진 구간만 들립니다. 긴 파트는 가위 툴로 나누세요. 트랙의 M(뮤트)·S(솔로) 상태, 상단 전역 M/S 버튼도 확인하세요.

피치·비브라토 툴이 회색이에요

피치/비브라토/익스프레션/타이밍 툴은 VOCALOID:AI 파트(V6 이후 보이스) 전용입니다. V3~V5 보이스는 이모션 툴과 어택/릴리즈 이펙트를 쓰세요.

보이스 언어를 바꿨더니 발음이 이상해요

발음기호는 자동 변환되지 않습니다. Job → Convert Phonemes to Match Language를 실행하세요. 잠금된(Phoneme Lock) 음표는 변환에서 제외됩니다.

녹음 버튼을 눌렀는데 피아노 소리가 나요

정상입니다. MIDI 녹음 중에는 VOCALOID 대신 피아노 소리로 모니터링하며, 녹음할 때마다 새 파트가 생깁니다. 트랙의 R 버튼이 켜져 있어야 합니다.

프로그램이 갑자기 꺼졌어요

환경설정 General의 Auto Backup을 켜 두면 15분마다 백업됩니다(한 번 이상 저장한 프로젝트만). 다시 열 때 복구 여부를 묻습니다.
